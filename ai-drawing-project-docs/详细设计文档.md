# **“幻境画廊” AI绘画平台 \- 详细设计文档 V1.1**

## **1\. 后端设计 (Backend Design)**

com.aidrawing.backend  
├── config           // 配置类 (WebSecurityConfig, WebSocketConfig, RabbitMQConfig, RedisConfig)

### **1.2. 数据库设计 (Database Schema)**

### **1.3. Redis设计 (Redis Design)**

#### **1.3.1. 核心应用场景**

1. **对象缓存**: 缓存访问频繁且不经常变更的数据，如画廊列表、作品详情。  
2. **API速率限制**: 限制单个用户在单位时间内的API请求次数。  
3. **分布式会话**: (远期) 在多实例部署时，存储用户会话信息。  
4. **排行榜**: (远期) 使用Sorted Set实现热门作品的实时排行。

#### **1.3.2. Key命名规范**

采用 \[业务名\]:\[子业务名\]:\[唯一标识\] 的格式，确保Key的可读性和唯一性。

* **示例**: gallery:page:1, drawing:details:uuid-1234-abcd, ratelimit:user:uuid-5678-efgh:generate\_api

#### **1.3.3. 核心Key设计**

| Key 示例 | Redis类型 | 描述与生命周期 (TTL) |
| :---- | :---- | :---- |
| gallery:shared:page::\[pageNumber\] | String (JSON) | 缓存分页后的公共画廊作品列表。TTL: 5-10分钟。 |
| drawing:details:\[drawingId\] | String (JSON) | 缓存单个作品的详细信息。TTL: 1小时。 |
| ratelimit:user:\[userId\]:\[api\_name\] | String | 简单的计数器，用于API速率限制。TTL: 60秒。 |
| rank:daily | Sorted Set | (远期) 每日热门榜，member为drawingId，score为点赞数。TTL: 24小时。 |

## **2\. 前端设计 (Frontend Design)**

前端设计对后端的缓存策略是无感的，其核心组件和页面职责保持不变。

### **2.1. 核心组件划分**

src  
├── api              // API请求模块 (auth.js, drawing.js)  
├── assets           // 静态资源 (images, styles)  
├── components       // 可复用组件 (LoginDialog.vue, NavigationBar.vue)  
├── router           // 路由配置 (index.js)  
├── services         // 服务模块 (websocketService.js)  
├── stores           // 状态管理 (Pinia \- userStore.js)  
├── views            // 页面级组件 (Home.vue, Studio.vue, Gallery.vue)  
└── App.vue          // 根组件

### **2.2. 核心页面设计**

* **App.vue (根组件)**  
  * **职责**: 作为整个应用的入口和布局容器。  
  * **核心逻辑**:  
    * 管理主导航栏的显示。  
    * 初始化WebSocket连接 (websocketService)。  
    * 监听WebSocket消息，并将最新的完成作品数据通过provide提供给所有子组件。  
    * 管理登录/注册对话框的全局状态。  
* **Studio.vue (创作中心)**  
  * **职责**: 提供完整的AI绘画参数输入界面和作品展示区。  
  * **核心逻辑**:  
    * 通过inject获取登录状态和最新的完成作品ref。  
    * 维护一个params响应式对象，双向绑定表单输入。  
    * handleSubmit方法：调用api/drawing.js中的接口提交生成任务，并进入加载状态。  
    * watch监听器：监听inject进来的lastCompletedDrawing的变化，一旦变化则更新imageUrl，并停止加载状态。  
* **Gallery.vue (公共画廊)**  
  * **职责**: 展示所有shared\_to\_gallery=true的作品。  
  * **核心逻辑**:  
    * onMounted生命周期钩子：调用api/drawing.js中的接口，获取公共画廊的图片列表。  
    * 使用v-for指令渲染图片列表，实现瀑布流或网格布局。  
    * (P1阶段) 点击图片时，将该图片的数据传递给一个详情模态框组件并显示它。

## **3\. API接口设计 (API Endpoints)**

API接口定义保持不变，但部分接口的性能表现和行为会因缓存和速率限制而改变。

| 功能模块 | HTTP方法 | URL路径 | 描述 | 请求体 (Body) | 响应 (Response) |
| :---- | :---- | :---- | :---- | :---- | :---- |
| **用户认证** | POST | /api/v1/auth/signup | 用户注册 | {username, email, password} | {message} |
|  | POST | /api/v1/auth/login | 用户登录 | {username, password} | {jwtToken, userId, username} |
| **AI绘画** | POST | /api/v1/ai-drawing/generate | 提交一个AI绘画任务 (需认证) | DrawingRequest DTO | {status: "QUEUED", message: "..."} |
|  | POST | /api/v1/ai-drawing/{drawingId}/share | 将指定作品分享到画廊 (需认证) | (无) | 200 OK |
| **作品查询** | GET | /api/v1/gallery | 获取公共画廊的作品列表 | (无) | List\<Drawing\> |
|  | GET | /api/v1/drawings/{drawingId} | 获取单个作品的详细信息 (需认证/授权) | (无) | Drawing |
|  | GET | /api/v1/drawings/my-history | 获取当前用户的历史作品 (需认证) | (无) | List\<Drawing\> |
| **图片服务** | GET | /api/v1/images/{filename} | 获取静态图片文件 | (无) | image/png (文件流) |
