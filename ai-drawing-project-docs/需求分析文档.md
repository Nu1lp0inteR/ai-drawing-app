# **“幻境画廊” AI绘画平台 \- 需求分析文档 V1.1**

## **1\. 项目愿景 (Project Vision)**

“幻境画廊”(Codenamed: "Illusion Gallery") 旨在成为一个集个人创作、社区分享、技术交流于一体的AI艺术创作与分享平台。它不仅为用户提供一个稳定、高效、易用的工具，让他们能够轻松地将创意转化为视觉艺术，更致力于构建一个充满活力和创造力的艺术家社区。

## **2\. 用户画像与核心场景 (User Personas & Key Scenarios)**

### **2.1. 创作者 (The Creator)**

* **画像**: 对AI绘画充满热情的技术爱好者、艺术家、设计师或普通用户。他们希望有一个私密、稳定且参数可控的环境来实验和创作自己的AI作品。  
* **核心场景**:  
  * **登录与认证**: “我希望能用我的邮箱和密码安全地登录我的账户，保护我的作品和隐私。”  
  * **参数化创作**: “我希望能精细地调整提示词、采样器、步数、CFG等参数，以实现我脑海中精确的画面效果。”  
  * **异步生成**: “我希望在提交一个耗时较长的生成任务后，可以关闭浏览器或做其他事情，完成后系统能通知我，而不是让我一直等待。”  
  * **个人作品管理**: “我希望能有一个个人空间，查看我所有历史生成作品，无论是分享的还是私密的。”  
  * **分享与交流**: “当我创作出一幅满意的作品时，我希望能一键将其分享到公共画廊，并看看其他人的作品和参数，以获得灵感。”

### **2.2. 访客/鉴赏家 (The Visitor / Connoisseur)**

* **画像**: 对AI艺术感兴趣的普通访客、寻找灵感的设计师、或其他创作者。他们不一定自己创作，但热衷于欣赏和发现优秀的作品。  
* **核心场景**:  
  * **浏览公共画廊**: “我希望能在一个美观的画廊页面，不受打扰地欣赏由社区用户分享的、最新或最热门的AI作品。”  
  * **查看作品详情**: “当我看到一幅惊艳的作品时，我希望能点击查看它的高清大图，以及作者使用的完整提示词和所有生成参数，这对我学习和启发非常有价值。”  
  * **无缝注册转化**: “在欣赏了这么多优秀作品后，我被激发了创作欲，我希望可以很方便地注册一个账户，开始我自己的创作之旅。”

## **4\. 非功能性需求 (Non-Functional Requirements)**

| 类别 | 需求ID | 需求描述 |  
| 性能 | NFR-PE-01 | 页面核心内容加载时间 (FCP) 应小于2秒。 |  
| | NFR-PE-02 | API接口的平均响应时间应小于200ms (不含AI生成时间)。 |  
| | NFR-PE-03 | (更新) 被缓存的API（如画廊）P99响应时间应小于50ms。 |  
| | NFR-PE-04 | 系统应能支持至少50个并发用户同时进行图片生成任务而无明显延迟。 |  
| 可扩展性 | NFR-SC-01 | 系统架构应支持未来水平扩展，可通过增加后端服务实例来提升处理能力。 |  
| | NFR-SC-02 | (新增) 用户会话管理应是无状态的，会话数据存储在Redis中以支持分布式部署。 |  
| 安全性 | NFR-SE-01 | 用户密码必须经过加盐哈希处理后存储。 |  
| | NFR-SE-02 | 所有API接口，特别是涉及用户数据的，必须经过JWT认证和授权。 |  
| | NFR-SE-03 | 防止SQL注入、XSS、CSRF等常见的Web攻击。 |  
| 可用性 | NFR-AV-01 | 系统核心功能应保证99.9%的在线可用率。 |  
| 易用性 | NFR-US-01 | UI/UX设计应简洁、直观，符合用户心智模型，无需阅读文档即可上手使用。 |
