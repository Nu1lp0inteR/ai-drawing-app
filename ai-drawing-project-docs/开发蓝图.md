# **“幻境画廊” AI绘画平台 \- 开发蓝图 V1.1**

## **Phase 0: 核心平台搭建 (已完成)**

* **目标**: 验证核心技术链路，实现从任务提交到结果展示的完整闭环。  
* **关键成果**:  
  1. 前后端项目骨架搭建。  
  2. 用户注册与登录功能。  
  3. 异步任务提交与处理流程。  
  4. 与ComfyUI的集成与通信。  
  5. 数据库与文件持久化。  
  6. WebSocket实时结果通知。  
  7. 基础的创作中心UI和画廊UI。

## **Phase 1: 性能优化与体验完善 (预计周期: 1-2周)**

* **目标**: 引入Redis提升核心性能，并补全核心的用户体验闭环，让平台从“可用”变为“好用且快”。  
* **关键任务**:  
  1. **【高优】集成Redis并实现画廊缓存**:  
     * **后端**: 添加spring-boot-starter-data-redis依赖。配置Redis连接。  
     * **后端**: 在DrawingService的getSharedDrawings方法上添加@Cacheable注解。  
     * **后端**: 在shareToGallery方法上添加@CacheEvict注解，确保数据一致性。  
  2. **【高优】画廊作品详情**:  
     * **后端**: 创建 GET /api/v1/drawings/{drawingId} 接口，并为其添加@Cacheable缓存。  
     * **前端**: 在 Gallery.vue 中，实现点击图片弹出模态框，显示高清大图和所有生成参数。  
  3. **【中优】个人作品历史**:  
     * **后端**: 创建 GET /api/v1/drawings/my-history 接口。  
     * **前端**: 创建 History.vue 页面，允许用户查看、删除、分享/取消分享自己的所有作品。  
  4. **【低优】“一键复用”功能**:  
     * **前端**: 在画廊详情模态框中，增加“复用参数”按钮，点击后跳转到创作中心并将所有参数自动填充。

## **Phase 2: 社区化与服务治理 (预计周期: 3-4周)**

* **目标**: 引入社区互动元素，并基于Redis实现初步的服务治理，提升用户粘性和系统稳定性。  
* **关键任务**:  
  1. **【高优】API速率限制**:  
     * **后端**: 利用Redis和AOP（切面编程）实现一个注解@RateLimit，并应用到generate等关键API上。  
  2. **【中优】点赞与热门排行**:  
     * **后端**: 扩展数据库。设计点赞API。使用Redis的Sorted Set实时更新热门作品排行榜。  
     * **前端**: 在画廊和作品详情中添点赞按钮，并开发新的“排行榜”页面。  
  3. **【中优】模型选择**:  
     * **后端**: 设计API以获取ComfyUI中可用的模型列表（可缓存）。修改任务提交逻辑以支持模型参数。  
     * **前端**: 在 Studio.vue 中添加模型选择的下拉框。  
  4. **【低优】作品评论**:  
     * **后端**: 设计 comments 表和相关API。  
     * **前端**: 在作品详情页添加评论区功能。

## **Phase 3: 长期演进与商业化探索**

* **目标**: 扩展平台能力，探索可持续的运营模式。  
* **关键任务**:  
  1. **高级绘图功能**:  
     * 逐步支持“图生图”、“ControlNet”、“局部重绘”等更复杂的AI绘画工作流。  
  2. **分布式会话管理**:  
     * 将用户会话（JWT黑名单等）从内存管理迁移到Redis，为后端服务的水平扩展做准备。  
  3. **商业化探索**:  
     * 为重度用户提供基于订阅的Pro账户，提供更快的生成队列、独占的GPU资源或更多的存储空间。  
     * 引入积分系统，用户可以通过每日签到等方式获取积分，用于图片生成。  
  4. **多平台支持**:  
     * 开发移动端应用或响应式布局，优化移动端体验。
